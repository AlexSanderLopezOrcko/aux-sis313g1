Preguntas Teóricas

1) Formas de conectar HTML con JavaScript

Existen dos formas principales de conectar un archivo HTML con JavaScript:

a) JavaScript interno

Consiste en escribir el código JavaScript directamente dentro del archivo HTML utilizando la etiqueta script.

Ejemplo:

<script>
    console.log("Hola mundo");
</script>

b) JavaScript externo

Consiste en crear un archivo separado con extensión .js y enlazarlo al archivo HTML utilizando la etiqueta script con el atributo src.

Ejemplo:

<script src="script.js"></script>

Esta forma es la más recomendada porque permite organizar mejor el código.

2) Cómo visualizar resultados de JavaScript en la consola

Pasos:

  1. Abrir el archivo HTML en el navegador.
  2. Presionar la tecla F12 o hacer clic derecho e ir a "Inspeccionar".
  3. Ir a la pestaña llamada "Consola" o "Console".
  4. Ejecutar código JavaScript utilizando console.log().
  5. Los resultados aparecerán en la consola del navegador.

Ejemplo:

console.log("Hola desde JavaScript");

3) Variables en JavaScript

Las variables son espacios en memoria que permiten almacenar información.

var

Fue la forma original de declarar variables en JavaScript. Actualmente ya no se recomienda utilizar porque puede generar problemas de alcance y redeclaración. 

var nombre = "Juan";
console.log(nombre);

let

Permite declarar variables que pueden cambiar su valor. 

let edad = 20;
edad = 21;
console.log(edad);

const

Se utiliza para declarar variables constantes cuyo valor no cambiará. 

const pais = "Bolivia";
console.log(pais);

Actualmente se recomienda utilizar let y const en lugar de var, porque ofrecen mayor seguridad y mejor control del alcance de las variables.
